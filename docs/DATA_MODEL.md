# 데이터 모델

상태: 첫 PR의 저장 요구사항 요약입니다. 현재 DB와 Repository는 구현하지 않았습니다. 다음 문서 PR에서 키·관계·불변조건을 확정하고 저장 기능 PR에서 Room 스키마와 테스트를 작성합니다.

| 예정 데이터 | 책임 |
| --- | --- |
| 문제 기록 | 문제 ID·유형·생성 버전·조건 전체·선택 내역·실제 노출/풀이 시간·정오/시도/시간 초과/무효 여부 |
| 화면 사이클 | 사용자에게 보이는 10문제·훈련 모드·혼합 4/3/3 순환·진행/완료 상태 |
| 유형별 학습 묶음 | 같은 유형·조건의 유효 10문제·AI 학습 포함 여부·완료 상태 |
| 난이도 상태 | 유형별 기억 시간·대기 시간·선택지 수·nullable 풀이 제한 |
| 복원 이력 | 단축 전후 값·미복원 잔량·선택지 단계·복원 이벤트 |
| AI 결정 | 허용 후보·선택 행동·선택 모드·적용 대기/적용 상태·변경 전후 조건·다음 묶음 연결 |
| 밴딧 학습값 | 유형/행동별 선택 경험·할인 유효 횟수·누적 보상·마지막 갱신 시각 |
| 설정(DataStore) | 안내·효과음·개발 비교 모드 등 |

문제 완료, 묶음 완료, 보상 갱신은 트랜잭션과 고유 ID로 중복 적용을 막습니다. 중단된 문제는 무효 처리 후 같은 조건의 새 문제로 대체하고 완료된 문제와 미완성 묶음은 보존합니다.

시간 판정에는 주입 가능한 단조 증가 시계를 사용합니다. 날짜 표시용 시각은 별도로 저장합니다. 시간제한 없음은 0초가 아닌 nullable 값으로 구분합니다. AI 선택 여부와 학습 포함 여부는 화면 사이클 완료 여부와 별도 필드로 구분합니다.

전체 필드 요구사항과 평균 계산 기준은 [SPEC.md](SPEC.md) 7~8절, 복원 규칙은 12절, 저장 원칙은 16절을 따릅니다.
