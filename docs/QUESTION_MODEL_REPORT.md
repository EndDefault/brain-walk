# 공통 출제 모델 추가 학습 결과

2026-10-01 · **추가 학습과 분리 시험을 완료했으나 앱 배포 기준에는 미달합니다.** 실험 재현용으로 가중치를 보관하며, 현재 Android 앱에는 연결하지 않았습니다.

## 보관한 모델과 선택 근거

[v0.2 공통 보정 모델](../models/question-author/v0.2-common-experimental/README.md)은 Qwen3-0.6B 원본에 적용하는 약 9MB LoRA 가중치입니다. 9월 30일 완료한 1회차 모델에서 전체 출제 형식을 추가 2회 학습했습니다. 개인 기록은 사용하지 않았습니다. 색·그림·숫자 약점, 기록 부족, 느린 정답 등을 포함한 300개 가상 프로필을 사용했습니다.

검증 30건에서 유형 판단은 **18/30**, 관찰된 혼동 재출제는 **8/10**이었습니다. 정답률 요약과 유형 균형 학습으로 추가 2회 집중 보정한 후보는 유형 판단이 **7/30**으로 떨어져 보관 대상에서 제외했습니다. 더 오래 학습한 모델을 자동으로 더 좋은 모델로 취급하지 않았습니다.

같은 검증 첫 10건·같은 제한 생성 방식으로 비교하면 1회차 모델의 유형 판단은 **1/10**, 보관 모델은 **6/10**입니다. 전체 검증 30건과 이 10건을 혼동하지 않습니다. 짧은 기록 질문과 예시를 넣은 질문은 각각 6/30, 집중 보정 후보의 어댑터를 합치지 않고 실행한 판단도 7/30이었습니다. 이 진단들은 완성된 출제안의 평가가 아닙니다.

## 학습 및 검증 방법

- 학습 300·검증 30·시험 50 프로필을 분리했습니다. 자료는 직접 작성한 규칙으로 만든 가상 사례이며 실제 380명을 모집한 자료가 아닙니다.
- 검증 자료로 보정 방식과 보관할 모델을 선택한 뒤 시험 50건을 한 번 평가했습니다. 시험 결과로 다시 튜닝하지 않았습니다. 이후 개선을 진행하면 새로운 시험 분할이 필요합니다.
- 최초 1회차에는 옵티마이저 상태가 없어 가중치에서 새 옵티마이저로 시작했습니다. 새 실행부터는 5단계마다 가중치·옵티마이저·스케줄·난수·다음 자료 위치를 저장합니다. 실제 1단계 중지 후 `next_row=8`부터 복원했습니다.
- 전체 출제 추가 학습에는 유형·혼동 보기·기억 대상에 높은 비중을 줬습니다. 가중 검증 손실은 4.81799 → 0.54455였으며, 이전 일반 손실과 비교하지 않습니다. 손실 감소를 출제 정확도로 대신 보고하지 않습니다.
- 선택된 추가 학습 실행 시간은 약 14.7분, PyTorch 최대 할당 GPU 메모리는 2.68GiB입니다. 준비·다른 실험·출제 평가 시간은 제외합니다.
- 계약·자료·패키징 테스트 18개, 작은 로컬 모델의 학습 복원·손실·토큰 제한·진단 테스트 12개로 총 **30개 통과**했습니다. 이번에는 Android 앱 코드를 변경하지 않아 Android 테스트를 다시 실행하지 않았습니다.

정답 라벨은 ‘유형별 관찰 12개 이상, 최저 정답률과 다음 유형 간 차이 0.20 이상’이라는 실험 규칙으로 작성했습니다. 실제 사용자 적합성·학습 효과를 증명하는 기준이 아닙니다. 이 규칙 자체로 라벨을 맞히는 것은 모델의 우수성 근거가 아닙니다.
