# 규칙 검증 예제

구현 전에 고정하는 가상 입력과 기대값입니다. 단위는 초이며 각 행은 독립적입니다. 실행된 앱 테스트 결과가 아닙니다. 난이도 엔진 PR에서 해당 사례를 실제 Kotlin 테스트로 옮깁니다.

## 복원 잔량

기억 이력 `20→16(4), 16→10(6)`에서 부분 복원하면 `10→13`, 최신 잔량 3입니다. 이후 전체 복원은 `13→16`까지만 수행하고, 그 다음 하락에서 이전 잔량 4를 사용해 20까지 복원합니다.

풀이 이력 `31→26(5)`에서 연속 부분 복원은 `26→28(잔량 3) →29(잔량 2) →30(잔량 1)`입니다. 잔량 1의 절반 내림은 0이므로 이후 부분 복원에서는 30을 유지합니다. 전체 복원 시 31로 복원합니다.

## 보상 갱신

기존 KEEP `(횟수 2, 합 1.5)`, MEMORY `(1, 0.75)`, SOLVE `(0, 0)`에서 MEMORY의 새 보상 1이 오면 할인 후 KEEP `(1.9, 1.425)`, MEMORY `(1.95, 1.7125)`, SOLVE `(0,0)`입니다. 동일 결정의 보상 재전송에는 이 상태가 바뀌지 않아야 합니다.

## 모집단 계산

10문제 중 첫 정답 7개, 두 번째 정답 1개, 세 번째 정답 1개, 실패 1개이면 C=7, A/W의 분모는 9입니다. 최종 정답 9개의 풀이 시간 합이 90초, 시도 가중 합이 120초이면 A=10, W=120/9초입니다. 실패 문항의 시간은 A/W에 더하지 않습니다. M은 첫 정답 7개의 실제 노출 시간만 평균합니다.

전부 실패하면 C=0, M/A/W=null입니다. 연습·무효 문항은 이 10문제에 포함하지 않습니다.
