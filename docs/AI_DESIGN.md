# AI 설계

상태: 첫 PR의 기준 요약입니다. 아직 AI 코드는 없으며 다음 문서 PR에서 결정·보상 연결 예제와 검증 사례를 확장합니다. 전체 규칙은 [SPEC.md](SPEC.md) 9~14절을 따릅니다.

규칙 엔진은 실행 가능한 후보를 만들고, 유형별 할인 UCB는 그중 `KEEP`, `ADJUST_MEMORY`, `ADJUST_SOLVE`를 선택합니다. `C=0~3`의 복원과 `C=4~6`의 유지는 고정 규칙이므로 밴딧 선택 횟수에 포함하지 않습니다.

```text
discountFactor = 0.95
explorationCoefficient = 0.3
meanReward = rewardSum / effectiveCount
score = meanReward + 0.3 * sqrt(ln(1 + totalEffectiveCount) / effectiveCount)
p = 다음 유형별 유효 10문제의 첫 선택 정답 수 / 10
reward = max(0, 1 - abs(p - 0.8) / 0.8)
```

과거 선택 경험이 없는 실행 가능 행동을 KEEP → MEMORY → SOLVE 순서로 한 번씩 시도합니다. 이후 동점도 같은 순서로 처리합니다. 선택 경험 여부는 할인된 횟수와 별도로 보존합니다.

결정은 화면 사이클 종료 후 실제 적용합니다. 적용된 결정과 다음 유형별 학습 묶음을 연결하고, 해당 묶음 완료 시 보상을 한 번만 반영합니다. 같은 유형의 행동별 횟수·누적 보상에 먼저 할인율을 적용하고 선택 행동에 새 횟수와 보상을 더합니다.

화면 사이클은 혼합 10문제일 수 있지만 학습 묶음은 같은 유형·같은 조건 10문제입니다. 묶음 완료 후 같은 화면 사이클의 추가 문제는 사용자 기록에 남기고 이미 완료된 AI 학습에는 포함하지 않습니다.

비교 규칙 모드는 같은 후보 계산을 사용하고 학습 연결을 분리합니다. 목표 정답률 80%는 게임 설계값이며 인지 향상이나 임상 효과를 주장하지 않습니다.
