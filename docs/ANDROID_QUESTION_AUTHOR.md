# Android 출제 모델 연결 · 2026-10-06

정식 게임 시작은 **실제 학습 모델 추론 → 출제안 검증 → 10문제 저장 → 게임 시작** 순서입니다. Qwen3-0.6B 원본에 공통 LoRA v0.2를 병합하고 GGUF Q8_0으로 변환한 모델을 APK에 포함했습니다. 앱에는 네트워크 권한이 없으며 설치 후 모델/API 다운로드가 필요하지 않습니다.

## 모델이 결정하는 것

- 앱은 종합 4/3/3 유형 배정, 보기 개수, 시간, 허용 재료를 고정합니다.
- 모델이 각 문제의 기억 대상과 서로 다른 오답 재료를 선택합니다. JNI의 제한 디코더는 JSON·도구 형식을 채우고, 선택지가 갈리는 토큰은 모델 logits에서 고릅니다. 규칙으로 고른 문제를 모델 결과로 표시하지 않습니다.
- 최근 같은 조건에서 완료한 유형별 최대 60개 기록을 기기 안에서 요약합니다. 첫 정답 수, 정답 시간, 최근 대상, 관찰된 혼동을 입력합니다. 연습과 중단 문항은 포함하지 않습니다.
- 앱은 허용 ID·유형·개수·중복·최근 대상 반복을 검증하고 보기 순서·문제 ID·정답 판정은 직접 처리합니다.
- 모델의 가중치는 플레이 중 바꾸지 않습니다. 난이도를 고르는 기존 Discounted UCB의 보상 학습은 계속됩니다. v0.2의 약한 유형 판단 평가 실패는 이번 연결로 해결되지 않았습니다.

## 준비·저장·복원

`QuestionPreparation`은 UI와 저장 트랜잭션 밖에서 한 묶음만 준비합니다. 게임 완료 기록과 다음 난이도를 먼저 커밋하고, 결과 화면에서 다음 묶음을 준비합니다. 준비된 계획은 Room v4의 `authored_plans`에 보관하며 조건·기록·회차에서 만든 키를 시작 시 재검사합니다. 한 계획은 한 게임만 소비하고 다음 문항과 재시작은 같은 저장된 계획을 사용합니다.

첫 시작에는 ‘AI가 문제를 준비하고 있어요’를 표시합니다. 준비 취소는 정식 게임을 만들지 않습니다. 실패하면 다시 시도하거나 ‘기본 문제로 시작’을 선택합니다. 모델 추론 시간 상한은 180초입니다. 준비 중 사용자가 기본 문제를 선택해도 늦게 끝난 응답이 게임을 바꾸지 않습니다.

`MODEL` 문제는 ‘AI가 구성한 문제’, 대체 출제는 ‘기본 문제’로 표시합니다. 문제 콘텐츠의 출처와 모델 버전, 계획의 생성 시간·대체 사유를 저장합니다. 콘텐츠 호환 버전과 모델 버전은 별도입니다. 미완료 문항의 중단 재개는 기존 규칙으로 새 대상 하나를 만들고 기본 문제로 구분하며 이후 슬롯은 저장한 모델 문제를 사용합니다. 연습은 기존 1문제이며 저장/모델 출제 대상이 아닙니다.

다른 PC에서 모델을 받은 후 일반 Android 빌드를 실행합니다.

```powershell
./tools/download_android_model.ps1
./gradlew.bat :app:assembleDebug
```

가중치 해시는 빌드와 최초 앱 내부 복사에서 확인합니다. ARM64 태블릿과 x86_64 에뮬레이터용 고정 네이티브 라이브러리를 저장소에 포함합니다. Android 8/API 26 이상 64비트 기기 대상입니다. 모델·내부 사본·앱을 설치할 여유 저장 공간이 필요합니다.

원본부터 재현할 때는 기존 학습 전용 환경에서 `sentencepiece==0.2.1`, `cmake==3.31.6`을 추가하고 `tools/export_android_model.py`를 실행합니다. `tools/build_android_author.ps1`은 NDK 28.2.13676358과 고정 llama.cpp 커밋 `5e03bdd8700948b9c41c54dd1b00f28a2aebc03f`를 사용합니다. 고지 원문은 `assets/licenses/`에 포함하며 메뉴 버튼을 다시 추가하지 않습니다.

공식 runtime 참고: [llama.cpp Android 빌드 안내](https://github.com/ggml-org/llama.cpp/blob/5e03bdd8700948b9c41c54dd1b00f28a2aebc03f/docs/android.md). 추론 속도는 아래 에뮬레이터 측정이며 실물 태블릿의 성능을 뜻하지 않습니다.

## 실제 확인

별도 검증 패키지에서 **탑재 모델 추론·검증·10문제 진행·중간 저장 복원**을 통과했습니다. 첫 실행은 내부 모델 복사를 포함해 37,122ms였습니다. 출력은 `MODEL`, 문제 10개, 실제 선택 정답과 기록 저장을 확인했습니다. 화면 테스트도 실제 모델로 게임 시작 버튼부터 첫 정답 저장까지 확인합니다. 보통 화면 회귀 테스트에서는 속도를 위해 명시적 테스트용 출제기를 주입하며 실제 모델 계측과 구분합니다.

실물 태블릿 속도·RAM, 모든 난이도에서의 생성 속도, 실제 사용자에 대한 맞춤 효과는 확인하지 않았습니다. 기존 가상 자료의 약점 분류 성능과 [평가 결과](QUESTION_MODEL_REPORT.md)는 그대로 남깁니다. 앱 연결 성공을 그 성능 개선으로 해석하지 않습니다.
