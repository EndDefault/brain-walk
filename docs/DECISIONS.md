# 주요 결정

2026-10-06 현재 구현에 영향을 주는 결정만 유지합니다. 단계별 작업 메모와 과거 화면 기록은 Git 이력에서 확인할 수 있습니다.

## 게임과 AI

- 정식 게임은 색·그림·숫자 혼합 10문제입니다. 유형별 연습은 1문제 체험이며 저장·난이도 학습에서 제외합니다.
- 한 게임의 유효 10문제를 합산해 다음 게임의 공통 난이도 하나를 정합니다. 유형별 부분 기록을 다른 게임과 합치지 않습니다.
- 출제 모델은 APK에 포함한 Qwen3-0.6B + 공통 LoRA v0.2의 GGUF Q8_0입니다. 기억 대상과 오답 보기를 구성하고 앱이 개수·유형·중복을 검증합니다. 약점 판단 성능의 한계는 [평가 보고서](QUESTION_MODEL_REPORT.md)에 공개합니다.
- 개인 기록은 기기 안에 저장하고 다음 출제의 입력으로 사용합니다. 생성 모델 가중치는 플레이 중 재학습하지 않습니다. Discounted UCB는 난이도 선택 경험으로 보상을 갱신합니다.
- 결과 저장 뒤 다음 10문제를 백그라운드에서 준비합니다. 준비 취소는 게임을 만들지 않으며, 사용자가 선택한 기본 출제는 모델 출제와 구분해 표시·저장합니다.

## 데이터와 UI

- Room v4와 보존 마이그레이션을 사용합니다. 앱 종료·진행 종료는 완료 성적을 지우지 않습니다. 이전 유형별 정책의 이력은 보존하고 통합 정책과 구분합니다.
- 중단 문항은 같은 조건의 새 대상으로 교체합니다. 답변·보상·판정은 저장 트랜잭션 성공 후 화면에 반영합니다. 판정은 단조 시각을 사용합니다.
- 홈은 게임 이름과 학습하기·학습 현황·게임 설명 세 버튼입니다. 공통 테마·컴포넌트, 큰 글자·버튼, 글자 200%와 세로 스크롤을 사용합니다.
- 개발 진단·라이선스 화면 버튼은 제거했습니다. Pretendard·Qwen·llama.cpp·네이티브 런타임의 필수 고지는 저장소와 APK에 보존합니다.
- 네트워크 권한과 서버 연동, 자동 백업을 사용하지 않습니다. 개인 DB·서명 키·토큰·로컬 SDK 설정은 Git에서 제외합니다.

## 빌드와 저장소

- Android API 26 이상 ARM64 기기와 x86_64 에뮬레이터를 대상으로 합니다. compile/target API 36, Gradle 8.14.4, AGP 8.13.2, Kotlin 2.2.21 등 검증한 조합을 고정합니다. 버전 변경은 별도 호환성 확인 후 진행합니다.
- Gradle 실행은 JDK 21, Java/Kotlin 출력은 17입니다. 한글 Windows 경로의 테스트 인코딩은 `file.encoding=COMPAT`로 맞춥니다. 상세 버전은 [README](../README.md#고정한-빌드-구성)와 [의존성 목록](DEPENDENCIES.md)에 있습니다.
- 공개 저장소와 기능별 커밋을 사용합니다. 브랜치 흐름은 `feature/* → develop → main`이며 개발 PR은 `develop` 대상입니다. `main`은 최종 검증 후 별도 PR로 반영합니다.
- `docs/`에는 현재 설계·모델 평가 요약·최신 검증 결과·대표 화면을 유지합니다. 중간 캡처·진단 JSON·인계 메모·로그는 `.artifacts/`에서 로컬로 관리합니다.

실행 여부와 남은 검증은 [검증 보고서](TEST_REPORT.md), 난이도 규칙의 세부 해석은 [AI 설계](AI_DESIGN.md)와 [규칙 예제](RULE_EXAMPLES.md)를 따릅니다.
