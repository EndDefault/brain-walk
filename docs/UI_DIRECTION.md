# 화면 디자인 방향

2026-09-23 사용자 후속 요청: **큰 게임 이름과 세 버튼을 가진 클래식 게임 메뉴**. 이전 기록 중심 홈 대신 기록은 별도 화면에 둡니다.

상태: 메인·학습 선택·학습 현황·게임 설명을 구현했습니다. 정식 기록은 Room에서 조회합니다. 이전 PR의 파스텔/기록 중심 홈 스크린샷은 과거 실행 기록입니다.

2026-10-06 제출 전 정리: 게임 플레이 화면은 유지하고 메뉴·설명·학습 현황을 다듬었습니다. 글꼴 고지와 개발 진단 화면/버튼을 제거하고, 배포 APK의 글꼴 고지는 유지합니다. 아래 내용은 현재 디자인 기준입니다.

## 시각 기준

- 한글 글꼴은 Pretendard 1.3.9 원본 Regular·Bold·Black을 앱에 포함해 인터넷 없이 사용합니다. SIL OFL 1.1 원문과 저작권 고지는 저장소와 APK 자산에 보존합니다. [외부 자료·라이선스](../THIRD_PARTY_NOTICES.md)를 참고합니다.
- 메뉴는 옅은 회색(#F2F5F6), 짙은 남색(#162F43), 청록색(#006B63)을 사용합니다. 유형별 그래프는 청록·파랑·보라와 수치/유형명을 함께 표시합니다. 게임 화면의 크림색 배경과 기억 재료 팔레트는 변경하지 않습니다.
- 메인은 게임 이름 ‘기억 산책’을 64sp 굵은 글자로 강조합니다. 남색 제목 패널의 황금색 포인트와 직접 작성한 도형 아이콘을 사용하며, 메뉴는 기존 세 개를 유지합니다.
- 기록은 큰 숫자, 유형별 막대그래프, 최근 정답률 선그래프로 묶습니다. 그래프는 0~100% 공통 축과 실제 분모를 사용하며 기록이 없을 때 추세를 만들지 않습니다.
- 메인 버튼 글자는 30sp, 높이는 최소 88dp입니다. 본문 22sp, 보조 정보 20sp, 나머지 버튼 최소 64dp를 유지합니다. 시스템 글자 확대를 제한하지 않으며 200%와 좁은 화면에서 줄바꿈·세로 스크롤을 지원합니다.
- 정오·선택 상태는 색상뿐 아니라 문구·테두리·표식으로 구분합니다. 소리나 애니메이션에만 필요한 정보를 담지 않습니다.
- 새로운 그림·아이콘이 필요하면 직접 작성한 도형을 우선하고 외부 자산은 출처와 라이선스를 함께 관리합니다.

## 공통 스타일과 화면 코드

웹의 `global.css`에 해당하는 역할은 `ui/theme/`과 `ui/components/`가 나눠 담당합니다. 새 화면에서는 자체 글꼴·색·버튼을 다시 만들지 않고 아래 공통 기준을 사용합니다.

| 수정할 내용 | 위치 |
| --- | --- |
| 배경·본문·버튼·테두리 색 | `ui/theme/Color.kt` |
| 글꼴·굵기·크기·줄 높이 | `ui/theme/Type.kt`: `MaterialTheme.typography`, 게임 숫자는 `GameTextStyles` |
| 간격·최소 버튼 높이·최대 화면 폭 | `ui/theme/Dimensions.kt`: `AppDimensions` |
| 전체 앱에 스타일 연결·모서리 모양 | `ui/theme/Theme.kt`: `MemoryStepsTheme` |
| 기본/큰 버튼, 채움/테두리 버튼, 대화상자 버튼 | `ui/components/ActionButton.kt` |
| 스크롤 페이지·큰 화면 제목·구역 제목 | `ui/components/Page.kt` |
| 메뉴 전용 색·모서리·너비 | `ui/theme/MenuStyle.kt`: 게임 테마와 분리 |
| 메뉴 페이지·버튼·도형 아이콘·반응형 배치 | `ui/components/MenuComponents.kt` |
| 실제 기록 집계 표시·그래프·빈 상태 | `ui/screens/records/RecordMetrics.kt`, `RecordCharts.kt`, `RecordsScreen.kt` |
| 게임의 그림·색·숫자 표시 | `ui/components/MemoryItemView.kt` |
| 유형명·게임 조건 공통 문구 | `ui/components/TrainingText.kt` |

기본 버튼은 22sp·최소 64dp, 큰 버튼은 30sp·최소 88dp입니다. 홈 메뉴와 게임 하단 진행 버튼은 큰 버튼을 사용합니다. 페이지/단계 제목은 38sp, 구역 제목은 28sp, 본문은 22sp, 보조 정보는 20sp입니다. 고정 높이로 글자를 자르지 않고 내용과 글자 배율에 맞춰 늘어납니다. 게임 팔레트와 Canvas 그림 좌표는 문제 콘텐츠이므로 UI 배경색·여백 기준과 분리합니다.

`ui/screens/` 아래 `home`, `learn`, `records`, `guide`, `training`이 각 화면을 담당합니다. `MemoryStepsApp.kt`는 화면 이동과 앱 수준 대화상자를 연결합니다. 게임 폴더는 단계 배치(`TrainingScreen`), 표시(`TrainingIndicators`), 보기(`AnswerOptions`), 일시정지(`PauseMenu`), 결과(`TrainingSummary`), 상태 관리(`TrainingViewModel`)로 나눕니다. 게임 판정·난이도·DB 로직은 기존 `game/`, `difficulty/`, `ai/`, `data/`에 둡니다.

## 메인과 학습 선택

메인은 큰 게임 이름 아래 **학습하기 → 학습 현황 → 게임 설명** 순서로 버튼 세 개만 둡니다. 태블릿에서도 한 열이며 넓이를 760dp로 제한해 가운데 정렬합니다. 첫 행동을 청록색으로 강조하고 나머지 메뉴는 흰색으로 구분합니다.

학습하기 화면 위에 **게임 시작**을 두고, 진행 중이면 **게임 이어하기**와 완료 수를 표시합니다. 아래 **연습하기**에 **색·그림·숫자** 버튼을 둡니다. 넓은 화면은 세 버튼을 한 줄, 좁은 화면이나 큰 글자는 한 열로 배치합니다.

## 정식 게임과 연습

| 시작 경로 | 한 사이클 | 화면의 설명 |
| --- | --- | --- |
| 게임 시작 | 색·그림·숫자 혼합 10문제 | 정식 기록 자동 저장 |
| 연습하기 → 색 | 색 1문제 체험 | 성적·AI 학습 제외 |
| 연습하기 → 그림 | 그림 1문제 체험 | 성적·AI 학습 제외 |
| 연습하기 → 숫자 | 숫자 1문제 체험 | 성적·AI 학습 제외 |

종합에서 4개가 배정되는 유형은 완료 사이클마다 색→그림→숫자로 순환하며 앱 종료 후에도 유지합니다. 연습은 정식 사이클·성적·AI 원본 기록에 영향을 주지 않습니다.

연습 상단 진행은 **1 / 1문제**입니다. 정답 또는 기회 소진 결과를 확인한 뒤 하단의 **연습 마치기**로 학습 선택에 돌아갑니다. 다음 문항이나 10문제 결과 화면을 요구하지 않습니다. 정식 게임의 10문제 결과 화면은 그대로 유지합니다.

## 학습 현황

완료 게임 수·푼 문제 수·첫 선택 정답률을 크게 표시합니다. 유형별 막대그래프는 첫 선택 정답 수/완료 문항 수, 별도 막대는 3회 기회 내 정답 비율입니다. 기록 없음은 ‘—’로 표시해 실제 0%와 구분합니다. 최근 30회 기록 중 완료된 게임 최대 10회만 시간순 선그래프로 표시하며 단일 기록은 점 하나입니다. 난이도가 달라질 수 있음을 안내하고 이를 최고 기록이나 능력 향상으로 표시하지 않습니다. 접근성 설명에는 각 점의 날짜·분자·분모·정답률을 포함합니다.

최근 기록은 5회부터 시작해 최대 30회까지 펼칠 수 있고 진행 중/완료/진행 종료를 구분합니다. 공통 난이도에는 기억 시간·대기 시간·보기 수·풀이 제한을 큰 값으로 표시합니다. 진행 중에는 합산 완료 수를 표시합니다. 넓은 화면은 유형/추이 그래프를 나란히 두고 작은 화면·큰 글자는 한 열로 배치합니다. 원본 기록, 조회 범위, Room 스키마는 변경하지 않습니다.

## 게임과 결과

게임 화면은 상단의 문제 번호·유형과 일시정지, 중앙의 현재 단계·기억 대상 또는 보기, 하단 고정 진행 버튼으로 구성합니다. 중앙 내용만 스크롤하고 다음/다음 문제 버튼은 그림과 떨어진 화면 아래에 유지합니다.

‘기억하세요’ 등 안내는 가운데 위에 38sp로 표시합니다. 기억 대상은 화면 크기에 따라 220~340dp로 키우고 가운데 배치합니다. 기억 시간은 64sp 숫자, 대기 시간은 160sp 숫자로 3·2·1을 크게 표시합니다. 정답 시에는 중앙에 56sp ‘정답입니다’만 보여 주며 정답 그림을 반복하지 않습니다.

오답을 고르면 남은 기회만 갱신하고 ‘다른 보기를 골라보세요’ 문구를 추가하지 않습니다. 틀린 보기는 흐리게 비활성화하고 읽기 설명으로 선택 불가 상태를 전달합니다. 추가 문구 때문에 보기 위치가 이동하지 않습니다.

게임 중 ‘학습 선택으로’ 버튼은 없습니다. 문제 번호 옆의 일시정지 또는 시스템 뒤로가기를 누르면 계속하기·뒤로가기(학습 선택)·홈으로 돌아가기 메뉴를 엽니다. 메뉴가 열리면 대상과 보기를 즉시 숨기고 타이머를 중단합니다. 완료 기록은 유지하며 미완료 문항은 같은 단계의 새 문제로 이어갑니다. 10문제 결과 화면에서는 학습을 마치는 홈 버튼을 제공합니다.

결과에서는 “10문제 중 8개를 한 번에 맞혔어요”처럼 실제 기록을 사용합니다. 종합은 전체 결과와 각 유형의 분모를 함께 표시합니다. 사이클 종료 뒤 적용할 조건은 쉬운 말로 안내합니다. 밴딧 점수, 내부 계산식, 근거 없는 향상·예방 효과는 사용자 화면에 표시하지 않습니다.

## 적용 순서와 확인

메뉴·정식/연습 플레이·학습 현황과 오프라인 난이도 AI를 연결했습니다. 원본 기록·진행·게임별 통합 학습 묶음·공통 난이도·밴딧 학습값은 재시작 뒤 복구하며, 중단된 문항만 새 대상으로 다시 시작합니다. 개발 진단 화면과 UI를 통한 비교 모드 전환은 제거했습니다. 생성 모델 연결은 이번 UI 작업에 포함하지 않습니다.

각 UI PR에는 실제 에뮬레이터 스크린샷, 작은 화면·글자 200% 결과, 미구현 상태를 구분해 올립니다. Galaxy Tab A9+ 실물과 시니어 사용성 확인은 기기 검증 단계에 남겨 둡니다.
