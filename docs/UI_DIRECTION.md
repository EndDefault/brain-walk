# 화면 디자인 방향

2026-09-22 사용자 선택: **차분한 기록형 — 절제된 색상, 학습 기록과 진행 상황 중심**.

상태: 다음 화면 구현의 기준입니다. 현재 앱의 홈·안내와 PR #1 스크린샷은 초기 실행 확인용이며 최종 디자인이 아닙니다. 이 문서 PR에서 Compose 화면은 변경하지 않습니다.

## 시각 기준

- 흰색·연한 회색 바탕과 짙은 글자로 읽기 편한 화면을 만듭니다. 강조색은 차분한 남색 계열 한 가지를 중심으로 사용합니다. 게임의 색 기억 문제는 별도 팔레트를 사용합니다.
- 현재의 넓은 파스텔 카드 반복, 큰 감성 문구, 장식용 기호를 줄입니다. 제목은 ‘학습 현황’, ‘훈련 시작’, ‘학습 기록’처럼 기능을 설명합니다.
- 기록은 실제 수치와 날짜를 정렬해 보여주고 얇은 구분선과 간격으로 묶습니다. 모든 내용을 둥근 카드로 감싸지 않습니다.
- 본문 22sp, 보조 정보 20sp를 기본으로 검토하고 버튼은 최소 64dp를 유지합니다. 시스템 글자 확대를 제한하지 않으며 200%와 좁은 화면에서 줄바꿈·세로 스크롤을 지원합니다.
- 정오·선택 상태는 색상뿐 아니라 문구·테두리·표식으로 구분합니다. 소리나 애니메이션에만 필요한 정보를 담지 않습니다.
- 새로운 그림·아이콘이 필요하면 직접 작성한 도형을 우선하고 외부 자산은 출처와 라이선스를 함께 관리합니다.

## 홈의 정보 순서

1. **학습 현황:** 마지막 학습 날짜, 완료 사이클 수, 유효 문제 수. 첫 이용은 “첫 훈련을 시작하면 기록이 표시됩니다”를 표시합니다.
2. **이어하기:** 진행 중인 사이클이 있을 때 해당 훈련 종류와 완료한 문제 수/10을 표시합니다. 새 훈련과 경쟁하는 여러 강조 버튼을 만들지 않습니다.
3. **훈련 시작:** ‘종합 훈련’과 ‘유형별 훈련’을 분명하게 구분합니다. 종합 훈련은 홈에서 바로 접근할 수 있는 주요 시작 버튼입니다.
4. **유형별 현황:** 색·그림·숫자별 첫 선택 정답률과 현재 기억 시간·선택지 수·풀이 제한을 정렬해 표시합니다.
5. **전체 기록:** 날짜·유형·조건별 상세 기록으로 이동합니다. 동일 조건의 자료가 있을 때만 변화 정보를 보여줍니다.

기록이 없는 상태에서 임의의 성적·그래프·추세를 채워 넣지 않습니다. 로컬 저장 기능 구현 전에는 기록 조회가 완성된 것처럼 표시하지 않습니다.

## 두 훈련 경로

| 시작 경로 | 한 사이클 | 화면의 설명 |
| --- | --- | --- |
| 종합 훈련 | 색·그림·숫자 혼합 10문제 | “색·그림·숫자를 섞어서 연습해요” |
| 유형별 훈련 → 색 | 색 10문제 | “색을 집중해서 연습해요” |
| 유형별 훈련 → 그림 | 그림 10문제 | “그림을 집중해서 연습해요” |
| 유형별 훈련 → 숫자 | 숫자 10문제 | “숫자를 집중해서 연습해요” |

종합 훈련에서 4개가 배정되는 유형은 완료 사이클마다 색→그림→숫자로 순환합니다. 유형별 난이도와 누적 기록은 두 경로에서 공유합니다. 종합을 세 유형의 훈련 30문제를 연속 실행하는 기능으로 만들지 않습니다.

## 게임과 결과

게임 화면은 유형·문제 순서, 현재 단계, 기억 대상 또는 보기, 필요한 버튼·시간·남은 시도만 명확하게 보여줍니다. 게임 도중 홈의 기록 정보가 주의를 분산시키지 않도록 합니다.

결과에서는 “10문제 중 8개를 한 번에 맞혔어요”처럼 실제 기록을 사용합니다. 종합은 전체 결과와 각 유형의 분모를 함께 표시합니다. 사이클 종료 뒤 적용할 조건은 쉬운 말로 안내합니다. 밴딧 점수, 내부 계산식, 근거 없는 향상·예방 효과는 사용자 화면에 표시하지 않습니다.

## 적용 순서와 확인

게임 화면 PR에서 기억·대기·풀이·결과의 공통 테마·글자·버튼을 이 방향에 맞춥니다. 종합/유형별 시작 경로는 훈련 모드 PR에서 실제 엔진에 연결하고, 홈 대시보드 PR에서 저장된 기록으로 위 정보 구조를 완성합니다. 초기 홈의 시각 정리는 게임 화면 작업과 함께 수행합니다.

각 UI PR에는 실제 에뮬레이터 스크린샷, 작은 화면·글자 200% 결과, 미구현 상태를 구분해 올립니다. Galaxy Tab A9+ 실물과 시니어 사용성 확인은 기기 검증 단계에 남겨 둡니다.
