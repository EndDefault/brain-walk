# 화면 디자인 방향

2026-09-23 사용자 후속 요청: **큰 게임 이름과 세 버튼을 가진 클래식 게임 메뉴**. 이전 기록 중심 홈 대신 기록은 별도 화면에 둡니다.

상태: 메인·학습 선택·학습 현황·게임 설명을 구현했습니다. 정식 기록은 Room에서 조회합니다. 이전 PR의 파스텔/기록 중심 홈 스크린샷은 과거 실행 기록입니다.

## 시각 기준

- 크림색 바탕(#FFF9EA), 짙은 남색(#173B5E), 남색 버튼의 흰 글자로 읽기 편한 화면을 만듭니다. 게임의 색 기억 문제는 별도 팔레트를 사용합니다.
- 메인은 게임 이름 ‘기억 산책’을 64sp 굵은 글자로 강조합니다. 감성 문구·카드 장식 대신 제목·구분선·큰 직사각형 버튼을 사용합니다.
- 기록은 실제 수치와 날짜를 정렬해 보여주고 얇은 구분선과 간격으로 묶습니다. 모든 내용을 둥근 카드로 감싸지 않습니다.
- 메인 버튼 글자는 30sp, 높이는 최소 88dp입니다. 본문 22sp, 보조 정보 20sp, 나머지 버튼 최소 64dp를 유지합니다. 시스템 글자 확대를 제한하지 않으며 200%와 좁은 화면에서 줄바꿈·세로 스크롤을 지원합니다.
- 정오·선택 상태는 색상뿐 아니라 문구·테두리·표식으로 구분합니다. 소리나 애니메이션에만 필요한 정보를 담지 않습니다.
- 새로운 그림·아이콘이 필요하면 직접 작성한 도형을 우선하고 외부 자산은 출처와 라이선스를 함께 관리합니다.

## 메인과 학습 선택

메인은 큰 게임 이름 아래 **학습하기 → 학습 현황 → 게임 설명** 순서로 버튼 세 개만 둡니다. 태블릿에서도 한 열이며 넓이를 680dp로 제한해 가운데 정렬합니다.

학습하기 화면 위에 **게임 시작**을 두고, 진행 중이면 **게임 이어하기**와 완료 수를 표시합니다. 아래 **연습하기**에 **색·그림·숫자** 버튼을 둡니다. 넓은 화면은 세 버튼을 한 줄, 좁은 화면이나 큰 글자는 한 열로 배치합니다.

## 정식 게임과 연습

| 시작 경로 | 한 사이클 | 화면의 설명 |
| --- | --- | --- |
| 게임 시작 | 색·그림·숫자 혼합 10문제 | 정식 기록 자동 저장 |
| 연습하기 → 색 | 색 10문제 | 성적·AI 학습 제외 |
| 연습하기 → 그림 | 그림 10문제 | 성적·AI 학습 제외 |
| 연습하기 → 숫자 | 숫자 10문제 | 성적·AI 학습 제외 |

종합에서 4개가 배정되는 유형은 완료 사이클마다 색→그림→숫자로 순환하며 앱 종료 후에도 유지합니다. 연습은 정식 사이클·성적·AI 원본 기록에 영향을 주지 않습니다.

## 학습 현황

완료 게임 수·완료 문제 수·첫 선택/최종 정답 수·유형별 첫 선택 정답과 최근 30회 기록을 표시합니다. 진행 중/완료/진행 종료를 구분합니다. 완료 기록은 진행 종료 후에도 보존합니다. 기록이 없으면 빈 상태 안내를 사용하며 가짜 수치나 향상 추세를 만들지 않습니다. 조건별 상세 비교와 난이도 표시는 후속 구현입니다.

## 게임과 결과

게임 화면은 유형·문제 순서, 현재 단계, 기억 대상 또는 보기, 필요한 버튼·시간·남은 시도만 명확하게 보여줍니다. 게임 도중 홈의 기록 정보가 주의를 분산시키지 않도록 합니다.

결과에서는 “10문제 중 8개를 한 번에 맞혔어요”처럼 실제 기록을 사용합니다. 종합은 전체 결과와 각 유형의 분모를 함께 표시합니다. 사이클 종료 뒤 적용할 조건은 쉬운 말로 안내합니다. 밴딧 점수, 내부 계산식, 근거 없는 향상·예방 효과는 사용자 화면에 표시하지 않습니다.

## 적용 순서와 확인

메뉴·정식/연습 플레이·학습 현황을 연결했습니다. 저장된 원본 기록과 진행은 재시작 뒤 복구하며, 중단된 문항만 새 대상으로 다시 시작합니다. AI 난이도와 학습값은 아직 구현하지 않았습니다.

각 UI PR에는 실제 에뮬레이터 스크린샷, 작은 화면·글자 200% 결과, 미구현 상태를 구분해 올립니다. Galaxy Tab A9+ 실물과 시니어 사용성 확인은 기기 검증 단계에 남겨 둡니다.
